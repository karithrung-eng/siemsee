# เซียมซี้! — เขย่าดวง ป่วนวง

เกมปาร์ตี้เซียมซีภาษาไทยสำหรับวงเพื่อน 20+ ใช้มือถือเครื่องเดียววางกลางวง
เปิดเว็บ → ตั้งวง → เขย่า → อ่านคำสั่ง → เห็นว่าใครต้องทำ → รอบต่อไป

เว็บเป็นไฟล์นิ่งล้วน (HTML/CSS/JS) ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก
ข้อมูลทุกอย่าง (จำนวนคน ชื่อ หมวด คำสั่งที่เพิ่มเอง เสียง) เก็บใน `localStorage` ของเครื่องที่เล่นเท่านั้น
แต่ละวงจึงไม่ปะปนกัน และการเพิ่มคำสั่งของคนหนึ่งไม่เปลี่ยนเกมของคนอื่น

## รันในเครื่อง

```bash
npm install
npm run dev          # เปิด http://localhost:5173
npm test             # ทดสอบตรรกะ (vitest)
npm run build        # สร้าง dist/ สำหรับโฮสต์ทั่วไป
npx vite preview --port 4173 &
npm run e2e          # ทดสอบบนเบราว์เซอร์จริงด้วย Playwright (ต้องมี Chromium)
```

## Deploy

ผลลัพธ์อยู่ใน `dist/` (ใช้ path แบบ relative โฮสต์ใต้โฟลเดอร์ย่อยได้) อัปขึ้นโฮสต์ไฟล์นิ่งที่มี HTTPS ได้ทุกเจ้า เช่น

- **GitHub Pages**: push โปรเจกต์ขึ้น GitHub แล้วใช้ workflow `.github/workflows/pages.yml` ที่แนบไว้ (Settings → Pages → Source: GitHub Actions)
- **Netlify / Cloudflare Pages / Vercel**: build command `npm run build`, output `dist`
- **ไฟล์เดียว**: `npm run build:single` ได้ `dist-single/index.html` ไฟล์เดียวที่รวมทุกอย่าง (ยกเว้นฟอนต์ Kanit จาก Google Fonts ซึ่งมีฟอนต์ไทยของเครื่องเป็นสำรอง)
- **Claude Artifact**: `npm run build:artifact` ได้ `dist-single/artifact.html`

## โครงสร้าง

```
src/
  logic/      กติกาล้วน ไม่แตะหน้าจอ — ทดสอบได้ทั้งหมด
    seats.ts    ซ้าย/ขวา/ตรงข้าม/คู่สุ่ม (กติกาเดียวทุกหน้า)
    resolve.ts  แปลงการ์ด + เลขที่สุ่มได้ → ผู้เกี่ยวข้องและบทบาท
    deck.ts     สำรับไม่คืนใบ + ถุงสุ่มเลข เลี่ยงซ้ำติดกัน
    format.ts   ข้อความ "คนที่ต้องทำ" / คำสั่ง / แถบจำนวน (แยกกันเสมอ)
    types.ts    โครงสร้างการ์ด: ข้อความ / เป้าหมาย / จำนวน+หน่วย แยกฟิลด์
  data/cards.ts คลังคำสั่งเริ่มต้น 68 ใบ
  state/        สถานะ: storage (บันทึกในเครื่อง), store (ตั้งค่า), game (รอบ/แอนิเมชัน ยกเลิกได้)
  ui/           หน้าจอ: setup, play, library, editor, ผังวง, มาสคอต
  audio/        เสียงสังเคราะห์ Web Audio (ไม่มีไฟล์เสียง)
  input/        ลากเขย่า + เขย่าเครื่องจริง
tests/          unit test ตรรกะ
e2e/run.mjs     ทดสอบบนเบราว์เซอร์จริง (หลายขนาดจอ)
assets/         มาสคอต/โลโก้ (SVG, PNG)
docs/           รายการคำสั่งเริ่มต้น + ผลทดสอบ
```

## กติกาที่นั่ง

นั่งล้อมวงหันหน้าเข้ากลาง เรียงเลขตามเข็มนาฬิกา (มองจากด้านบน)
คนข้างซ้ายมือ = เลขถัดไป (+1) คนข้างขวามือ = เลขก่อนหน้า (−1) วนครบวง
คนตรงข้าม: วงเลขคู่ = +n/2, วงเลขคี่ = สุ่มจากสองตำแหน่งที่ไกลที่สุด และแสดงเลขที่เลือกจริงในคำสั่ง

## คำสั่งที่เพิ่มเอง

ใช้ตัวแทน `{player}` `{left}` `{right}` `{opposite}` `{random}` ในข้อความได้
ทุกตัวแทนจะกลายเป็น “เบอร์ N” และถูกไฮไลต์ในผังวงอัตโนมัติ จำนวนกับหน่วยเก็บเป็นฟิลด์แยก ไม่แยกตัวเลขจากประโยค
