# ผลทดสอบ เซียมซี้! (2026-10-11)

## Unit test ตรรกะ (vitest) — ผ่าน 18/18
- ซ้าย/ขวา/ตรงข้าม/คู่สุ่ม ครบทุกที่นั่งของวง 2–24 คน รวมการวนรอบหัว–ท้าย
- วงเลขคี่: คนตรงข้ามมาจากสองตำแหน่งที่ไกลที่สุด และเลขในคำสั่งตรงกับที่เลือกจริง
- การ์ดเริ่มต้น 68 ใบ × วง 2–24 คน × ทุกเลขที่สุ่มได้: เลขในข้อความถูกไฮไลต์ครบ ไม่มีตัวแทนค้าง
- เลขคู่/เลขคี่/คู่คี่เหมือนคนที่สุ่มได้/ทุกคน ไฮไลต์ถูกกลุ่ม
- เลือกผู้รับเอง: เลือกตัวเองได้ เปลี่ยนผู้รับแล้วแทนที่ ไม่สะสมคนหรือจำนวน
- สำรับไม่ออกใบซ้ำก่อนครบ ไม่ออกลักษณะเดียวกันติดกัน ไม่ออกเลขคนเดิมติดกัน เหลือใบเดียวก็ไม่ค้าง
- กดสุ่มซ้ำระหว่างลุ้นไม่สุ่มซ้อน เริ่มวงใหม่ระหว่างลุ้นยกเลิกงานเก่าทั้งหมด

## ทดสอบบนเบราว์เซอร์จริง (Chromium + Playwright) — ผ่าน 25/25
-  ตั้งวง: ปุ่มเพิ่ม/ลด 2–24 คน และปุ่มใหญ่พอ
-  ตั้งวง: ค่าเริ่มต้นเลือกครบ 3 หมวด ความยินยอมไม่ติ๊กให้เอง และมีเหตุผลใกล้ปุ่ม
-  ตั้งวง: ชื่อไม่บังคับ ไม่ใส่ชื่อแสดงแค่ “เบอร์ N”
-  เล่น: เขย่า → ไม้โผล่ → “สุ่มได้เบอร์ N” → คำสั่ง (โหมดลุ้นเต็ม)
-  เล่น: กดเขย่าซ้ำเร็ว ๆ ไม่สุ่มซ้อน
-  เล่น: ย้อนกลับระหว่างลุ้น ยกเลิกแอนิเมชันเก่า แล้วเริ่มใหม่นับรอบ 1
-  เล่น: ข้ามและรอบต่อไป นับรอบถูก ไม่มีคำสั่งซ้ำก่อนครบสำรับ
-  เล่น: คีย์บอร์ด Space เขย่า Enter รอบต่อไป Esc กลับ
-  เล่น: ลากซ้าย–ขวาที่กระบอกแล้วเขย่า
-  ผังวง: ไฮไลต์ตรงกับคำสั่งทุกแบบ และมีเครื่องหมายไม่พึ่งสีอย่างเดียว
-  เลือกผู้รับเอง: แตะเลือก เปลี่ยนแล้วไม่สะสม เลือกตัวเองได้
-  เสียง: ปิด/เปิดได้ และจำหลังรีโหลด
-  คลัง: เพิ่ม แก้ไข ปิด ลบ ค้นหา และเปิดคำสั่งเริ่มต้นกลับโดยไม่ลบของเรา
-  คำสั่งที่เพิ่มเองถูกสุ่มได้ และไฮไลต์ตามตัวแทน
-  บันทึก: จำนวนคน ชื่อ หมวด เสียง ยังอยู่หลังรีโหลด แต่ความยินยอมไม่ถูกจำ
-  บันทึก: เบราว์เซอร์บันทึกไม่ได้ ยังเล่นได้และแจ้งสั้น ๆ
-  เริ่มวงใหม่: เก็บชื่อและคำสั่งส่วนตัวไว้ นับรอบใหม่
-  พอดีจอ iPhone 14 + แถบ Safari (390×664): วง 6 คน ครบทุกคำสั่งเริ่มต้น ไม่ต้องเลื่อน
-  พอดีจอ iPhone SE + แถบ Safari (375×553): วง 6 คน ครบทุกคำสั่งเริ่มต้น ไม่ต้องเลื่อน
-  พอดีจอ Android 360×640 (360×640): วง 6 คน ครบทุกคำสั่งเริ่มต้น ไม่ต้องเลื่อน
-  พอดีจอ Pixel 7 + แถบ Chrome (412×780): วง 6 คน ครบทุกคำสั่งเริ่มต้น ไม่ต้องเลื่อน
-  วง 24 คน + คำสั่งยาวมาก + จอเล็ก 320×480: เลื่อนอ่านได้ครบ ปุ่มไม่บัง
-  วง 24 คนบนจอมือถือปกติ: ผังอ่านได้ ปุ่มกดได้
-  ขยายตัวอักษร 150%: ข้อความไม่ถูกตัด ปุ่มยังกดได้
-  การเข้าถึง: ปุ่มสำคัญมีชื่อ และไม่มี error ในหน้า

## ข้อจำกัดที่เหลือ
- ไม่มี WebKit/Safari ในเครื่องทดสอบ จึงยังไม่ได้ทดสอบบน iPhone จริง (ใช้ Chromium จำลองขนาดจอ iPhone แทน)
- การเขย่าเครื่องจริงทดสอบอัตโนมัติไม่ได้ (ต้องใช้เซนเซอร์จริง) ปุ่มเขย่า การลาก และคีย์บอร์ดใช้ได้เสมอ
- เมื่อเปิดผ่าน Claude Artifact กรอบหน้าเว็บไม่อนุญาตเซนเซอร์การเคลื่อนไหว ปุ่ม “เขย่าเครื่องจริง” จะแจ้งว่าไม่ได้รับอนุญาต ถ้าโฮสต์เองบน HTTPS (เช่น GitHub Pages) จะขออนุญาตได้ตามปกติ
- ฟอนต์ Kanit โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน
